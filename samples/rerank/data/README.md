# data

`scifact_30.json`은 [BEIR](https://github.com/beir-cellar/beir) 판 [SciFact](https://github.com/allenai/scifact)(Wadden et al., 2020)의 일부다. 테스트 질의 30개, 질의별 BM25 상위 30개 후보, 그 후보의 초록(앞 1,200자)만 담았다. `build_subset.py`로 다시 만들 수 있다.

SciFact는 CC BY-NC 2.0으로 배포된다. 이 파일도 같은 조건(저작자 표시, 비상업적 이용)을 따른다.
