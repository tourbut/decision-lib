## 확인 중 고친 결함

- 설정 앱 후보에 현재 상태가 없어 VPN 연결 뒤 같은 버튼을 다시 눌렀다. "(이미 적용됨)"을 붙였다.
- rooms 지도에서 문을 거치지 않고 출구에 갈 수 있었다. 벽을 막아 문이 유일한 길이 되게 고쳤다.
- 격자에서 한 칸 이동만 주면 실패했다. 높은 수준 행동 방식을 더하고 기본값으로 삼았다. 세 방식 결과를 README에 남겼다.
