## 확인 중 고친 결함

- 체결을 다음 블록 가격으로 해서 예측하는 움직임을 놓쳤다. 이 블록 가격 ± 스프레드 절반으로 고쳤다.
- 스프레드가 신호보다 커 모든 정책이 손해였다. 스프레드를 틱의 10분의 1로 줄였다.
- 손실 한도에서 거래만 멈추고 포지션은 남겨 손익이 계속 움직였다. 정리 후 중단하게 고쳤다.
