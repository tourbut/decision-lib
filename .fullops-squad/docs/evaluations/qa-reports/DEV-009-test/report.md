## 확인 중 고친 결함

- 메모리 미들웨어 테스트가 병렬 도구 실행 순서에 기대 간헐 실패했다. 순서와 상관없이 비교하게 고쳤다.
- 비밀 정규식이 "비밀번호는"처럼 조사가 붙은 한국어를 놓쳤다. 조사까지 보게 고쳤다.
- 처음 세션의 파일 내용이 200자보다 짧아 크기 기반도 사실을 다 지켰다. 실제 파일 길이에 가깝게 늘렸고, README에 그 이유를 적었다.
