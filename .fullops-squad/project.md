# 프로젝트 설정

setup에서 이 레포를 직접 확인하고 채운다. 원본 템플릿의 기술 스택·remote를 상속하지 않는다.

| 항목 | 값 |
|---|---|
| 제품 목적 | 미확정 — 레포에 README 제목(`decision-lib`)만 있음. 사용자 확인 필요 |
| 기본 브랜치 | `main` (remote `origin`, 역할 브랜치 `fullops/dev`) |
| 기술 스택·아키텍처 정본 | 미확정 — 소스·설정 파일 없음(초기 레포) |
| 공통 개발 기준 | [rules/common/README.md](rules/common/README.md) — `fullops-common-0.3.3` |
| 보안·코딩 규칙 | 미확정 — 기존 문서 연결 |
| 테스트·린트·빌드 명령 | 미확정 — 스택 없음. `lint/lint.json`의 `commands`는 빈 목록. 스택 결정 후 구성 필요 |
| 문서 언어 | 한국어 |

개발 문서 기본 경로는 `.fullops-squad/docs/`다. 기존 정본이 있으면 이동·복제하지 말고 아래 매핑과 산출물 인덱스를 해당 경로로 갱신한다.
외부 스킬의 `docs/agents/`는 이 레포에서 `.fullops-squad/docs/agents/`를 가리킨다.

## 공통 기준의 적용과 예외

공통 규칙은 기존 정본이 없는 부분의 기본값이다. 언어 관례·아키텍처·테스트 종류·커버리지는 실제 프로젝트 기준에 연결하고 기존 요구 수준을 낮추지 않는다. 보안·권한·리뷰 수락 기준은 임의 완화하지 않는다.

규칙 충돌과 승인된 예외는 항목·이유·적용 범위·승인 근거를 기록한다. 작업 지시서에는 이번 과제에서 사용하는 문서 경로와 기준 커밋 또는 스냅샷을 적는다. 규칙 개정은 사용자 수정본과 차이를 검토한 뒤 명시적으로 반영한다.

## 검사 구성 상태

- 2026-10-19 setup 시점 레포는 `README.md`만 있다. 언어·패키지 매니저·린터·테스트 러너·CI가 없다.
- 따라서 lint/test 명령을 연결하지 못했다. `lint/lint.json`의 `commands`는 빈 목록이며 검사 구성은 미완료다.
- 스택을 정하면 `lint/README.md`의 `레포별 lint 구성` 순서로 린터·타입 검사·테스트를 연결하고 이 절을 갱신한다.
